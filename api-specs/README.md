# API Specifications

OpenAPI 3.1.0 specifications for Device Manager services.

## Structure

- `schemas.yaml` - Shared schemas used across both APIs
- `statistics-api.yaml` - Public Statistics API (port 8080)
- `device-registration-api.yaml` - Internal Device Registration API (port 8081)
